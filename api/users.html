Users

List and retrieve the users who own records in your Dreamteam workspace. Users are the actors referenced by every record's owner_id and created_by fields.

List Users

GET /api/v1/users

Returns the users in your organization that you have access to. Sensitive fields (passwords, tokens, OTP codes, API keys) are never returned in this response.

Query parameters

page integerPage number, starts at 1. Defaults to 1.
page_size integerPage size. Default 20. Max 100 - higher values are silently capped at 100 (no error). Defaults to 20.
sort stringSort spec

Returns

A paginated user list with the same shape as records list responses (results + metadata). Each user object includes id, first_name, last_name, primary_email, username, role, title, status, sales_user, and created_at.

Fields

roleOne of admin, sales_manager, sales_member.
statusOne of ACTIVATED (can log in), CREATED (invited, not yet activated), SUSPENDED (access revoked).
sales_userBoolean. Whether this user is counted against the workspace's paid sales seats.

Sensitive fields are never returned

Tokens, passwords, API keys, and OTP codes are stripped from every user response.
