Concepts

The vocabulary the rest of this doc uses.

RecordOne row in Dreamteam - a contact, company, deal, note, meeting, or task. Each has a stable numeric id.
Object typeThe kind of record. One of contact, company, deal, note, meeting, task.
PropertyA field on a record - like first_name on a contact, amount on a deal. Full list per object type: Describe Object.
AssociationA link between two records - e.g. a contact belongs to a company. Full list: Association Definitions.
PipelineThe stages a deal moves through, from open to closed won/lost. Read via Pipelines.
