Authentication

Every request to the Dreamteam CRM API is authenticated with a Bearer token that identifies your organization. Grab a token from your profile, send it in an Authorization header, and you're set.

Get your API token

  1. Click your profile avatar (bottom-left corner)
  2. Click View Profile
  3. Scroll to the API Token section at the bottom
  4. Use the icons next to the masked token:
    • Reveal - show the token in plaintext
    • Copy - copy the token to your clipboard
    • Reset - rotate the token; the previous one is invalidated immediately

Your API token does not expire automatically. It stays valid until you regenerate it from your profile page. If you suspect a security breach, regenerate the token immediately - the previous token will stop working.

Using your token

Send every request to this base URL:

Base URL: https://api.dreamteamcrm.ai/api/v1

Include your token in the Authorization header on every call. Add a Content-Type when you're sending a body.

Header Value Required
Authorization Bearer <YOUR_TOKEN> Always
Content-Type application/json POST requests
Content-Type application/merge-patch+json PATCH requests

You don't need to send an organization id. The Bearer token already carries which workspace it belongs to. When you send a request, the API decodes the token and only ever touches that workspace's data. Switching workspaces means generating a new token in the new workspace.

Try your first call

With your token in hand, fetch all contacts in your workspace to confirm your setup works. Click Test Request to run it right here.

GET /api/v1/objects/{object}/records 
curl 'https://api.dreamteamcrm.ai/api/v1/objects/contact/records' \
  -H 'Authorization: Bearer <YOUR_TOKEN>'

You should get a JSON response with a results array. If you get 401, double-check that the token was pasted whole and that the header value starts with Bearer (with a trailing space).
