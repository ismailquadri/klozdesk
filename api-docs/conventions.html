Conventions

How the URLs in this doc are written, and the shape of the date values the API returns.

URL Placeholders

Endpoint examples in this doc use these placeholders. Substitute the actual value in your request.

PlaceholderDescriptionAllowed values
{object}The object typecontact, company, deal, note, meeting, task
{id} / {recordId}Numeric id of a recorde.g. 1015634

Timestamps

Record timestamps (like created_at and updated_at) are UTC in ISO 8601 format: YYYY-MM-DDTHH:MM:SS.ffffffZ. The trailing Z denotes UTC. When you send date values in requests (e.g. expected_close_date), use the same format. One exception: the timestamp field on error responses has no Z suffix and carries nanosecond precision (e.g. 2026-08-11T09:26:41.025999781).
